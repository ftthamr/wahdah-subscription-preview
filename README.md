# WAHDAH subscription preview

Static landing-page mockup with WAHDAH Singapore branding, featured vehicles, benefits, comparison table, FAQs and calls to action.

Open `index.html` directly. Logo, banner and vehicle photos are embedded. Lexend loads from Google Fonts with an Arial fallback.

The existing search layout is represented visually. Search and vehicle links lead to the existing WAHDAH subscription website; this preview does not change its booking, application or payment flow. Prices are fixed 36-month examples observed on 13 November 2026.

This is a design preview, not the live WAHDAH service.
